# Memory in World Models

**A categorized index of papers on memory in world models**

[简体中文](README_cn.md)

</div>

World models have to remember what they have already seen: a room the camera left a minute ago, an object that went out of view, a step of a task that is already done. This repository organizes papers on how that memory is represented, maintained, learned and evaluated, and how it is built into video, action and navigation world models. The first four top-level categories follow the analysis in the survey [The Past Frames the Future: Memory for Autoregressive Video Generation](https://arxiv.org/abs/2609.28466); the fifth groups work by the kind of world model. It currently lists 237 papers and 5 surveys.

## Papers by Category

Each paper has one primary category. World models built for a specific task (world action, navigation, or embodied video models) go under Memory Applications even when their contribution is a memory mechanism. Other categories a paper touches are listed as "Related" after its TL;DR. A paper ID is the category code plus a number: `[MR.Visual.2]` belongs to `MR.Visual` (Visual Memory), and a category without subcategories uses its top-level code, as in `[ME.3]`. Numbers only identify papers and say nothing about quality. Entries marked "Base" are not memory work themselves (foundation models or general-purpose benchmarks) but help in understanding the area.
